# Contributing

Use a fork and a focused pull request. Run `./scripts/validate.sh` before
submitting. Changes to tenant boundaries require tests for an allowed path and
a denied path, an updated threat model, and review from both platform and
security owners. Use Conventional Commit subjects and never include tenant
credentials, subscription data, kubeconfigs, or production evidence.

By participating, you agree to follow the
[Contributor Covenant](CODE_OF_CONDUCT.md).
