# Support

This project is community-supported. Use issues for reproducible defects and
discussions for design questions. Do not post credentials, kubeconfigs, tenant
names, or production logs. Security issues follow `SECURITY.md`.

Compatibility target: Python 3.11+, Kubernetes 1.30+, Azure CNI powered by
Cilium, and the AKS managed Istio add-on supported by the deployed AKS version.
Validate the exact AKS/Istio version combination in the target region before
production use.
